設定

アプリの表示言語 / App language

音声入力・文字起こしの言語 / Speech & transcription language

自動＝端末の言語設定に合わせます。発話ごとの自動判別は端末の音声認識が対応していないため、英語で話す日は English に切り替えてください。

AI文字起こし（Gemini）

録音と同時の文字起こしができない機種向け（この機種も該当）。録音した音声を、文字起こしのときだけ Google Gemini に送ります。キーはこの端末にのみ保存。
キーの無料発行：aistudio.google.com/apikey →「Create API key」→ コピーして上に貼り付け。

データのバックアップ

音声を含む全記録を1つのファイルにまとめます（APIキーは含めません）。共有シートからDrive等に保存できます。
※保存先フォルダを常時変更する設定は、ブラウザアプリの制約上できません（ネイティブ版で対応予定）。

書き出し

記録全体を Markdown で書き出せます（Obsidian にそのまま置ける形式）。
