# Koebi v0.1 — PWA 版

> 声で残す、自分だけの日記。＋やらなきゃ吐き出しBOX・きぶん記録・自分ケア・エビの成長。
> データは**すべて端末内**（IndexedDB）。サーバーには何も送らない。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（単一ファイルSPA。CSS/JSすべて内包） |
| `manifest.webmanifest` | PWAの名刺。ホーム画面追加時の名前・色・アイコンを定義 |
| `sw.js` | Service Worker。アプリの殻をキャッシュしてオフライン起動を可能に |
| `icons/` | エビアイコン（192/512/maskable） |
| `deploy.sh` | GitHub Pages への公開スクリプト |

## スマホで使うまで（3ステップ）

```
1. Mac のターミナルで:  zsh ~/Documents/nomacod/koebi/app/web/deploy.sh
2. 1〜2分待って、Nothing Phone の Chrome で
   https://<GitHubユーザー名>.github.io/koebi-app/ を開く
3. メニュー（︙）→「ホーム画面に追加」→ 以後アプリとして起動
```

初回録音時にマイク権限を聞かれるので「許可」。

## 技術メモ（なぜこの構成か）

- **PWA を選んだ理由**：HTTPS 配信さえあればマイク・オフライン・ホーム画面追加が使え、ネイティブ環境構築（Android Studio）なしで即日実機に届くから。UI/データ設計はそのまま将来のネイティブ版（Kotlin）に移植できる。
- **録音は MediaRecorder + Opus**（ロードマップ通りの高品質圧縮）。
- **文字起こしは端末内 SpeechRecognition**（無料・APIキー不要）。Android では録音と音声認識がマイクを取り合うことがあるため、録音画面では「動けばラッキー」扱い、吐き出しBOXでは音声認識のみを使う設計。
- **連続記録（streak）を採用しない理由**：途切れた瞬間にやる気ごと折れるのは ADHD 的に典型的な罠。Koebi のエビは「来た日の合計」だけで育つ。休んでも減らない。
- **プライバシー**：日記・音声・気分データはリポジトリに含まれない（端末の IndexedDB のみ）。public リポジトリに置くのはコードだけ。

## 既知の制限（v0.1）

- 録音中のリアルタイム文字起こしは端末により失敗する（録音自体は必ず残る）
- 音声ファイルの一括エクスポートは未実装（Markdownエクスポートはあり）
- iOS Safari は対象外（Android 優先。ロードマップ通り）
